# Лабораторная работа №4: Умножение матриц (CUDA)

**Выполнила:** Тимофеева Елизавета

## Описание
Программа реализует параллельное умножение матриц по технологии CUDA. 
Так как на локальной машине отсутствует графический ускоритель Nvidia, код был адаптирован для эмуляции CUDA-потоков на CPU с использованием OpenMP. Архитектура программы повторяет логику работы CUDA-ядра (сетка блоков и потоков).

## Результаты экспериментов
* Размер 256x256: 0.0082 с
* Размер 512x512: 0.0233 с
* Размер 1024x1024: 0.0951 с

## Запуск
```bash
g++ -O3 -fopenmp -o lab4 lab.cpp
./lab4
